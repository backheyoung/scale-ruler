# 📏 ScaleRuler Pro — 컴퓨터용 정밀 화면 자 & CAD 도면 배율·면적 측정기

**설치 없이 웹 브라우저에서 바로 사용하는 컴퓨터용 정밀 화면 자(Screen Ruler) 및 도면 배율 측정 스튜디오**입니다.  
도면이나 사진을 붙여넣고(`Ctrl + V`) 기준이 되는 두 지점만 클릭해 실제 수치를 입력하면, 그 비율에 맞춰 **거리(mm/cm/m/inch), 사각형 면적(㎡·평), 연속 구간 합계, 3점 각도**를 정밀하게 측정할 수 있습니다.

🔗 **웹사이트 바로가기:** [https://backheyoung.github.io/scale-ruler/](https://backheyoung.github.io/scale-ruler/)

---

## ✨ 주요 기능 (업그레이드 완료)

1. **🎯 마우스 2점 클릭 배율 보정 (`단축키: C`)**
   - 도면이나 사진에서 실제 길이를 알고 있는 구간(시작점 → 끝점)을 마우스로 클릭한 뒤 `"1500 mm"`처럼 실제 수치를 입력하면 전체 도면의 픽셀 대 실제 단위 비율이 즉시 자동 보정됩니다.
2. **💳 모니터 화면 1:1 실물 크기 보정 (신용카드 / 모니터 인치)**
   - 도면 없이 모니터 화면에 실제 물건을 대고 재고 싶을 때, 국제 규격 신용카드(`85.60 × 53.98 mm`) 슬라이더 또는 모니터 인치 프리셋(15.6인치 노트북, 24인치, 27인치, 32인치 등)으로 1:1 실물 눈금자를 맞출 수 있습니다.
3. **📐 4가지 정밀 측정 도구 + 끝점 드래그 미세 수정**
   - **거리 측정 (`M`)**: 두 지점 사이의 실제 거리($\Delta L$), 가로($\Delta X$), 세로($\Delta Y$), 각도($\theta$) 측정
   - **면적·평수 측정 (`S`)**: 방이나 사각형 대각선 두 점을 찍어 가로×세로 치수와 **면적(`m²` 및 `평` 자동 환산)** 동시 표시
   - **연속 거리 합계 (`P`)**: 여러 지점을 연달아 클릭하여 전체 둘레나 동선 총합 길이 측정
   - **3점 각도 측정 (`A`)**: 시작점 → 꼭짓점 → 끝점 세 곳을 클릭해 정확한 각도($^\circ$) 측정
   - **끝점 마커 드래그 수정 & 실행 취소 (`Ctrl+Z`)**: 이미 찍은 치수선의 양 끝 동그란 마커를 마우스로 드래그해 돋보기(4x/8x)를 보면서 1픽셀 단위로 미세 수정 가능
4. **📏 배율 연동 플로팅 눈금자 (`단축키: R`)**
   - 화면 위 어디로든 이동·길이 조절·가로/세로 회전·투명도 조절이 가능하며, 눈금 위를 클릭하면 **P1 / P2 핀**이 고정되어 두 핀 사이의 거리($\Delta$)를 계산해 줍니다.
5. **🏠 원클릭 샘플 평면도 체험 & 결과 내보내기**
   - 사진이 없어도 바로 테스트할 수 있는 **[🏠 샘플 도면]** 버튼 탑재
   - 측정된 치수선이 함께 그려진 **[💾 이미지 저장 (PNG)]** 및 측정 목록 **[엑셀저장 (CSV)]** 지원

## 🔒 업로드한 사진은 어떻게 되나요? (100% 로컬 처리 보안)

- 본 웹사이트에 불러오거나 붙여넣기(`Ctrl+V`)한 모든 사진·도면 파일은 **외부 서버나 클라우드로 단 1바이트도 전송되지 않습니다.**
- 웹 브라우저 표준 `FileReader` 및 `HTML5 Canvas` API만을 사용하여 **오직 사용자의 기기(브라우저 메모리) 안에서만 처리**되며, 창을 닫거나 새로고침하면 즉시 메모리에서 완전 소멸됩니다.

## 💰 광고 수익화 연동 방법 (Google AdSense / Kakao AdFit)

1. `app.js` 파일 상단의 `AD_CONFIG` 객체를 확인합니다.
2. **카카오 애드핏(Kakao AdFit)** 또는 **구글 애드센스(Google AdSense)**에서 사이트 승인 후 발급받은 광고 단위 코드를 입력하고 `enabled: true`로 변경하면 우측 사이드바와 하단 반응형 배너 영역에 자동으로 광고가 게재됩니다.
