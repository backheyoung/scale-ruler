ScaleRuler Pro는 서버리스 클라이언트(Client-Side Only) 아키텍처로 설계되었습니다. 사용자가 Ctrl+V로 붙여넣거나 파일 열기로 선택한 사진·설계 도면은 인터넷을 통해 외부 서버나 클라우드로 단 1바이트도 전송되지 않습니다.

① 내 컴퓨터 안에서만 열림

브라우저 표준 FileReader와 HTML5 Canvas 기술만을 사용하여 오직 사용자 본인의 PC·스마트폰 화면 메모리에만 그림을 표시합니다.

② 사이트 운영자도 볼 수 없음

별도의 파일 저장 서버나 데이터베이스(DB) 자체가 존재하지 않으므로, 웹사이트 제작자나 제3자가 사용자가 올린 도면이나 개인 사진을 열람하거나 수집하는 것이 원천적으로 불가능합니다.

③ 창을 닫으면 즉시 완전 소멸

브라우저 탭을 닫거나 새로고침(F5)하는 순간 메모리에서 이미지 데이터가 즉시 파기됩니다. 기업의 보안 도면이나 개인 사진도 안심하고 측정하세요.

💡 자주 묻는 질문 (FAQ)

Q. 화면을 마우스 휠로 확대/축소하면 측정 치수가 달라지나요?

아니요! 모든 기준선과 치수선은 원본 도면의 월드 좌표계를 기준으로 계산되므로, 마우스 휠로 아무리 확대해서 정밀하게 점을 찍어도 실제 치수(mm/cm/m)와 눈금자 간격이 정확하게 연동됩니다.

Q. 이미 찍은 치수선의 위치를 조금 수정할 수 있나요?

네! 측정 완료된 치수선의 양 끝 동그란 마커 위에 마우스를 가져가서 드래그하면 돋보기를 보면서 끝점 위치를 1픽셀 단위로 미세하게 수정할 수 있습니다.

Q. 측정한 도면을 이미지나 엑셀로 저장할 수 있나요?

상단 [💾 이미지 저장] 버튼을 누르면 도면 위에 치수선이 깔끔하게 그려진 PNG 파일이 다운로드되며, 우측 목록의 [엑셀저장] 버튼으로 CSV 표 파일을 내려받을 수 있습니다.
